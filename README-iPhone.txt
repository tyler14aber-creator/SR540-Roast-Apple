ROAST BENCH — iPHONE INSTALL

This package contains the Roast Bench web app.

IMPORTANT: Apple does not allow an unsigned .ipa file to be installed directly on an iPhone. The simplest no-App-Store version is a Home Screen web app.

To install:
1. Put roast_timer.html on a web host (GitHub Pages, Netlify, Cloudflare Pages, etc.).
2. Open its HTTPS address in Safari on your iPhone.
3. Tap Share.
4. Tap Add to Home Screen.
5. Turn on “Open as Web App” if iOS offers the option.
6. Tap Add.

Roast Bench will then launch from your Home Screen in an app-like full-screen window.

Recipes are stored locally in that browser/web-app installation.
